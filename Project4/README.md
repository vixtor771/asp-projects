# Project 4: Linear Predictive Coding

ECE 520.445/645 Audio Signal Processing, Fall 2026.

An LPC vocoder: estimates the prediction coefficients, gain and pitch of each frame, and re-synthesizes the speech from those parameters only. Includes a voicing/pitch estimator written from scratch and comparisons of order, frame rate, glottal pulse shape and residual excitation.

## How to run

Python 3.14.

```bash
cd Project4
pip install -r requirements.txt
python code/project4.py
```

The script prints all result tables and writes all outputs:

| Part | Code | Output |
|---|---|---|
| LPC analysis | `levinson`, `lpc_frame`, `encode` | printed parameters per second |
| Synthesis | `make_excitation`, `synth_filter`, `decode` | `output_audio/Sample1_lpc.wav` to `Sample10_lpc.wav`, `figures/reconstruction.png` |
| Voicing | `estimate_voicing`, `voicing_experiment` | `figures/voicing.png` |
| Rate vs quality | `sweep_rate_quality` | `figures/rate_vs_quality.png` |
| Glottal shapes | `glottal_pulse`, `glottal_experiment` | `figures/glottal_shapes.png` |
| Residual excitation | `residual_codec`, `residual_experiment` | printed table |
| Own recording | `part2` | `output_audio/my_recording_lpc.wav`, `my_recording_lpc_baseline.wav` |

Files in `output_audio/` that start with `extra_` are the comparison examples used in the report.
