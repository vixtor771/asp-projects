# Project 3: Head-Related Transfer Functions

ECE 520.445/645 Audio Signal Processing, Fall 2026.

Loads HRTFs from SOFA files, visualizes them across 20 subjects, computes the mean HRTF and per-subject MSE, and renders a sound source rotating around the listener (binaural surround sound with overlap-add).

## How to run

Python 3.14.

```bash
cd Project3
pip install -r requirements.txt
python project3.py
```

The script prints the SOFA file structure and the MSE results, and writes all outputs:

| Task | Code | Output |
|---|---|---|
| 2a Load HRIRs | `load_sofa`, `get_hrir`, `explore_sofa` | printed structure |
| 2b HRIR ↔ HRTF | `hrir_to_hrtf`, `hrtf_to_hrir` | `figures/2ab_hrir_hrtf.png` |
| 2c Apply an HRIR | `apply_hrir` | `figures/2c_apply_hrir.png`, `output_audio/2c_*.wav` |
| 2d Heatmaps | `azimuth_map`, `elevation_map`, `plot_heatmaps` | `figures/2d_heatmaps.png` |
| 2f Mean HRTF and MSE | `mean_and_mse` | `figures/2f_mean_hrtf.png`, printed MSE |
| 3 Surround sound tool | `spatialize` | `figures/3_surround_output.png` |
| 4 Experiments | `main` | `output_audio/<subject>_<audio>_az0_w60.wav` |

## Surround sound tool

```python
from project3 import spatialize
y, fs = spatialize("Data/HRTFs/id09_measured.sofa", "Data/Audio/speech.wav",
                   az_start=0, omega=60, out_path="out.wav")
```

`az_start` is the starting azimuth in degrees (0° = front, 90° = left) and `omega` the rotation speed in degrees per second.
